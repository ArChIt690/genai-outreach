Privacy and data handling

This local assessment application stores public X profiles/posts selected for review, test-consent references, exact approved outgoing messages, and events from the operator's tracked private conversations.

Access and purpose

Only the authenticated operator can view the workspace. OAuth credentials are encrypted on the server. The application uses X's official API. It does not scrape, send bulk campaigns, or send without exact-text approval and test-recipient authorization.

Optional model processing

Template drafting stays local. If an operator explicitly configures the Anthropic provider and acknowledges its data processing, selected public evidence and sender facts are sent to that provider. Private messages and account tokens are never included. The provider's applicable terms and retention settings must be reviewed before enablement. No model is trained by this application.

Storage and removal

Data remains in the installation's PostgreSQL database. Disconnect removes usable tokens and pauses new sends; it does not delete messages on X. Settings offers a local content purge. Minimal contact history prevents accidental recontact. The maintenance commands describe refresh, retention and full local deletion, including the resulting loss of historical duplicate protection.

Requests and contact

Contact the operator who provided this installation for access, correction or removal requests. The installer must provide their own contact details before sharing a hosted instance. This prototype has not been deployed publicly.
