# AI assistance and review

Codex generated the initial architecture, Python application, templates, tests and handoff documents during this development session. The developer must personally review and understand the code before submitting it as their work.

The implementation was checked with real PostgreSQL integration tests, mocked external contracts, concurrency and uncertainty scenarios, browser interaction, screenshot inspection, linting, compilation and dependency checks. A real browser test caught a referrer-policy/origin interaction that HTTP-only tests did not expose.

Runtime drafting defaults to a deterministic evidence template. It quotes selected public evidence and uses the operator's supplied purpose. The optional Anthropic Messages adapter is implemented with structured output validation and visible fallback, but no real model account was used here.

Model claim checks validate identifiers and exact source quotes, not complete semantic truth. Humans still inspect every personal claim and approve the exact saved version. No model can grant contact permission, approve or dispatch a message.

No live X or paid model verification is claimed. No candidate's private account information was collected to create synthetic tests.
